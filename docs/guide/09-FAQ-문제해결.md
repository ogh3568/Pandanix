# 9. FAQ · 문제 해결

## 실행

**start.bat 을 눌렀는데 창이 바로 닫혀요**
→ 명령 프롬프트를 열고 폴더로 이동해 `npm start` 로 실행하면 오류 메시지가 보입니다. 대부분 Node 미설치 또는 포트 충돌입니다.

**"포트 3210 가 이미 사용 중입니다"**
→ 이미 실행 중입니다. 브라우저에서 `http://localhost:3210` 을 여세요. 아니면 `settings.json` 의 `port` 변경.

**브라우저가 자동으로 안 열려요**
→ 직접 `http://localhost:3210` 입력. (`PANDANIX_OPEN=1` 환경변수가 자동 열기 스위치)

**다른 PC 에서 접속하고 싶어요**
→ 기본은 보안상 내 PC(127.0.0.1)에서만 접속됩니다. `set HOST=0.0.0.0` 으로 실행하면 같은 네트워크에서 접속 가능하지만, 인증이 없으므로 신뢰할 수 있는 망에서만 쓰세요.

**서버가 혼자 꺼져요 / 오래 쓰면 멈춰요**
→ `start.bat` 은 서버가 비정상 종료되면 3초 뒤 자동으로 다시 시작합니다(최대 5회). 원인은 `data\logs\pandanix.log` 에 남습니다. 긴 AI 응답 때문에 끊기는 일은 없도록 요청 시간 제한을 두지 않았고, 5분간 응답이 없을 때만 그 요청을 끊습니다.

**노트북 절전 후 돌아오니 "응답 중" 에서 멈춰 있어요**
→ 90초 안에 연결 끊김으로 감지되어 오류가 표시됩니다. 오류 말풍선의 **다시 시도** 를 누르세요.

**한글 폴더/파일 이름이 문제가 되나요**
→ 아닙니다. 다만 Windows 에서는 이름 끝의 점(.)이나 공백, `CON`/`NUL` 같은 예약 이름은 쓸 수 없어 자동으로 바뀌거나 거부됩니다. 메모장이 붙이는 BOM, Excel 의 CP949 CSV 도 자동 처리됩니다.

## AI

**응답이 없거나 오류가 나요**
→ 🩺 Doctor → 실시간 API 테스트. 메시지별 조치는 [5장 오류 표](05-AI-채팅.md#오류-메시지-읽기).

**회사 프록시 환경이에요**
→ `HTTPS_PROXY`(필요하면 `NO_PROXY`) 환경변수를 설정하고 `start.bat` 으로 실행하세요. 배치 파일이 `NODE_USE_ENV_PROXY=1` 을 함께 켜서 Node(22.21 이상)가 그 프록시를 사용합니다. 터미널에서 직접 실행할 때는 `set NODE_USE_ENV_PROXY=1` 을 먼저 하세요. 그래도 안 되면 IT 부서에 `api.anthropic.com`, `api.openai.com`, `generativelanguage.googleapis.com`, `opencode.ai` 허용 요청.

**모델 목록(⟳)이 비어 있어요**
→ 키가 없거나 권한이 없는 경우. 모델 ID 를 직접 입력해도 됩니다.

**응답이 중간에 끊겨요**
→ 설정 > 채팅 옵션 > 최대 출력 토큰 증가. 또는 "계속" 입력.

**참고자료를 AI 가 못 읽는 것 같아요**
→ pdf/xlsx/docx 는 내용이 전달되지 않습니다(파일명·설명만). md/csv/txt 로 변환해 올리세요. "참고자료 포함" 체크도 확인.

## 데이터

**답안이 사라졌어요**
→ 에디터 🕘 버튼으로 저장본(2분 간격, 최근 20개) 복원. 파일은 `data/answers/<문제집>/<문제>/history/`.

**문제집을 다른 PC 로 옮기려면**
→ ⋯ → 폴더로 내보내기 → 폴더 복사 → 📥 가져오기. 또는 `data/` 전체 복사.

**내장 문제집을 지웠는데 다시 보고 싶어요**
→ 왼쪽 **📚 내장 문제집** 에서 다시 설치하세요. 모든 내장 문제집이 여기에 있습니다.

## 보안

**API 키는 어디에 저장되나요**
→ `data/config/credentials.json`. git 제외, UI 에는 마스킹되어 표시.

**파일 접근 범위는 어디까지인가요**
→ 설정에서 허용한 폴더와 `data/` 만. 그 밖은 403 으로 거부됩니다.

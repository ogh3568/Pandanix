# 4. 답안 작성 (가운데 에디터)

## 기본

- 문제를 선택하면 가운데가 그 문제의 답안이 됩니다. 문제마다 따로 저장
- **자동 저장**: 입력을 멈추면 1.5초 뒤 저장. `Ctrl+S` 또는 **저장** 버튼으로 즉시 저장
- 하단에 **글자 수 (공백 제외)**, **제한 대비 남은/초과 글자**, **마지막 저장 시각** 표시

## 도구 모음

| 버튼 | 기능 | 단축키 |
|---|---|---|

| B / I / U / S | 굵게 / 기울임 / 밑줄 / 취소선 | Ctrl+B / I / U |
| Tx | 서식 지우기 | |

## 표 다루기

- 표 안에 커서를 두면 표 위에 작은 도구가 뜹니다: **행 + / 열 + / 행 − / 열 − / 머리글 전환 / 표 삭제**
- 셀에서 `Tab` 으로 다음 셀, 마지막 셀에서 `Tab` 하면 행 추가
- AI 채팅의 Markdown 표는 **답안에 삽입** 하면 실제 표로 들어옵니다
- Markdown 표 텍스트를 붙여넣어도 표로 변환됩니다

## 붙여넣기

- Word/웹에서 복사한 서식은 안전한 범위(제목, 굵게, 목록, 표, 링크)만 유지됩니다
- 이미지를 붙여넣으면 자동 업로드되어 삽입됩니다

## 내보내기 위치

- **다운로드**: 브라우저 다운로드 폴더
- **로컬 폴더에 저장**: 허용된 폴더([7장](07-파일-탐색기.md)) 중 선택. 파일명 지정 가능

## 저장 위치

`data/answers/<문제집id>/<문제id>/`
```
answer.json      현재 답안 (HTML) + 상태
history/*.html   저장본 (최근 20개)
attachments/     이미지·첨부
chat.json        이 문제의 AI 대화
```

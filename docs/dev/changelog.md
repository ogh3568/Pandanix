# 변경 이력

형식: `## 버전 (날짜)` 아래에 `- [영역] 내용`. 가장 최근이 위. 배포 전 작업은 **미배포** 섹션에 쌓았다가 버전을 올릴 때 이름을 바꾼다.

## 미배포
- [문서] 기능별 화면 캡처(번호 박스·라벨) 21장을 가이드에 삽입, 오프라인 HTML 가이드(`docs/html/`, `npm run docs:build`), 캡처 자동화(`npm run docs:shots`), 문서 점검기(`npm run docs:check`), 렌더러 이미지 지원
- [UI] 에디터 내보내기 메뉴를 공통 메뉴(Esc·방향키)로 통일

## 비고
- 2022년 주요 부품(클러치/브레이크) 교체 이력 있음 (비용 1,400만 원).
- 제조사 측 "HP-200M 은 2026년부터 순정 부품 공급 종료 예정" 공지(2025년 9월).
- 3호기가 정지하면 B-14 성형은 2호기에서 대체 생산 가능하나, 2호기 가동률이 이미 85% 라 잔업이 필요함.
- 잔업 시 시간당 추가 인건비 약 6만 원(2인 기준), 대체 생산 전환 준비(금형 교체)에 회당 약 2시간 소요.

# 대안별 비용/효과 추정 (운영팀 초안, 2025.10)

월 평균 출고: 약 3,200건. 현재 배송사: 빠른택배(건당 평균 배송비 6,800원).

## 대안 1. 포장재 변경 (완충재 + 모서리 보호대 추가)
- 추가 비용: 건당 약 1,900원 → 월 약 608만 원
- 기대 효과: 파손 건수 50~60% 감소 (포장재 업체 레퍼런스 기준)
- 준비 기간: 2주 (자재 발주 + 포장 매뉴얼 교육)
- 부작용: 포장 시간 건당 약 1.5분 증가

## 대안 2. 배송사 변경 (가구 전문 배송사 '세이프무브')
- 배송비: 건당 평균 9,400원 (현재 대비 +2,600원) → 월 약 832만 원 추가
- 기대 효과: 파손 건수 70~80% 감소 (전문 배송 + 설치 서비스)
- 준비 기간: 6주 (계약, 시스템 연동, 병행 운영)
- 부작용: 일부 도서 지역 배송 불가(전체 주문의 약 3%)

## 대안 3. 파손 보상 정책 강화 (즉시 환불/재배송 + 쿠폰)
- 추가 비용: 파손 건당 약 1만 5천 원 추가(쿠폰) → 현재 월 파손 약 130건 기준 월 약 195만 원
- 기대 효과: 파손 건수는 줄지 않음. 불만 후 재구매율 개선(추정 +10%p)
- 준비 기간: 1주

## 참고
- 현재 파손 1건당 평균 처리 비용(보상 + 재배송 + 상담 인건비): 약 9만 5천 원
- 최근 파손 증가 원인: 신규 입점 '대형 원목 테이블' 카테고리 매출 비중 확대(파손의 약 60% 가 해당 카테고리)

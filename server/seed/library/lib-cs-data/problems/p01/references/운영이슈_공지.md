# 10월 운영 이슈 공지 모음 (사내 게시판)

## [물류팀] 새벽배송 파트너 변경 안내 (9월 28일)
- 10월 1일부터 수도권 새벽배송 파트너가 '빠름로지스'로 변경됩니다.
- 전환 초기 2주간은 배송 기사 동선 조정으로 일부 지역 지연 가능성이 있습니다.
- 지연 시 고객 안내 문자는 파트너사 시스템에서 자동 발송됩니다. (※ 10월 첫 주 일부 누락 사례 확인, 원인 파악 중)

## [개발팀] 앱 v5.2 업데이트 배포 (10월 5일)
- 주요 변경: 결제 화면 개편, 장바구니 저장 방식 변경, 쿠폰 자동 적용 기능 추가
- 안드로이드 일부 기종에서 결제 화면 오류 제보가 들어오고 있어 확인 중입니다. 재현이 되는 고객 기종 정보가 있으면 개발팀에 공유해 주세요.

## [정산팀] 환불 처리 일정 안내 (10월 6일)
- 카드 결제 환불은 승인 취소 후 카드사 반영까지 영업일 기준 3~5일 소요됩니다.
- 쿠폰 사용 주문의 부분 환불 시 쿠폰 할인분은 환불되지 않으며, 쿠폰은 재발급됩니다. 이 내용이 고객 안내 문자에 빠져 있어 수정 예정입니다.

## [상품MD팀] 산지 변경 안내 (10월 2일)
- 딸기·시금치 산지가 10월부터 일부 변경되었습니다. 입고 검수 기준은 동일합니다.

## [마케팅팀] 10월 쿠폰 이벤트 안내 (10월 2일)
- '가을 장보기 쿠폰'(3천 원 / 4만 원 이상 구매 시) 이벤트를 10월 5일부터 18일까지 진행합니다.
- 앱 v5.2의 쿠폰 자동 적용 기능과 연동되며, 쿠폰 적용 오류 문의는 개발팀과 함께 확인해 주세요.
- 생일 쿠폰은 매월 1일 일괄 지급됩니다. 10월 지급분은 시스템 점검으로 10월 6일에 지급되었습니다.

## [CS팀] 기타 공지
- 10월 9일(한글날)은 배송 휴무였으며, 휴무 안내는 앱 공지사항에만 게시되었습니다.
- 10월 셋째 주 금요일 오후 2시 상담원 친절 교육(외부 강사) 예정.
- CS팀 회식은 10월 마지막 주 목요일입니다.

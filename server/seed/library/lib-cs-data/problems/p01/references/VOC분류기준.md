# 하루장터 VOC 분류 기준 (CS팀 내부 가이드)

개정: 2026년 3월 / 작성: CS팀

## 1. 유형 분류 (7개)
| 유형 | 포함 내용 | 주 담당 부서 |
|---|---|---|
| 배송 | 지연, 오배송, 미수령, 배송 장소 문제, 배송 안내 누락 | 물류팀 |
| 상품 품질 | 신선도 불량, 유통기한, 이물질, 상품 정보와 실물 불일치 | 상품MD팀 |
| 포장 | 파손, 냉장·냉동 보냉 불량, 포장재 과다·오염 | 물류팀 |
| 결제·환불 | 결제 오류, 이중 결제, 환불 지연·금액 오류, 정기결제 | 정산팀 |
| 앱·웹 오류 | 앱 종료·멈춤, 화면 오류, 장바구니·로그인 문제 | 개발팀 |
| 쿠폰·적립금 | 쿠폰 미지급·적용 오류, 적립금 내역 문제 | 마케팅팀 |
| 기타 | 상담 연결, 회원 정보, 제안 등 위에 해당하지 않는 것 | CS팀 |

※ 두 유형에 걸치는 경우 **고객이 실제로 겪은 피해의 원인**을 기준으로 하나만 고른다. (예: 보냉 불량으로 상한 고기 → '포장', 쿠폰 적용 시 결제 화면 멈춤 → '앱·웹 오류')

## 2. 심각도 기준
| 등급 | 기준 | 처리 목표 |
|---|---|---|
| A (긴급) | 위생·안전 문제(이물질 등), 고객 금전 피해(이중 결제, 환불 누락), 같은 건 재문의 2회 이상 | 당일 담당 부서 전달, 24시간 내 회신 |
| B (일반) | 서비스 불편, 일부 상품 불량 | 48시간 내 회신 |
| C (개선 제안) | 포장재 의견, 기능 제안 등 | 월간 보고에 포함 |

## 3. 우선순위 판단 방법
- 유형별 **건수**, **A등급 비율**, **재문의 비율**을 함께 본다.
- 같은 원인으로 보이는 VOC가 여러 건이면 하나의 이슈로 묶어 보고한다.
- VIP 고객 VOC는 등급과 별개로 팀장에게 공유한다.

# 문의 유형별 분석 (10월 1~2주, 전화+채팅)

작성: CS팀 데이터 담당 / 상담 기록의 유형 태그 기준

## 1. 유형별 비중과 평균 상담 시간
| 문의 유형 | 비중 | 평균 상담 시간(전화) | 셀프서비스 가능 여부 |
|---|---|---|---|
| 배송 위치·도착 시간 조회 | 32% | 2분 30초 | 가능 (앱 주문 내역에서 조회) |
| 교환·환불 접수 | 24% | 6분 | 일부 가능 (사진 첨부 접수 기능 개발 중) |
| 주문 변경·취소 | 14% | 4분 | 가능 (출고 전까지 앱에서 직접 가능) |
| 상품 문의 (원산지·보관법 등) | 15% | 3분 30초 | 일부 가능 (상세페이지 정보 보완 시) |
| 결제·적립금 | 8% | 5분 | 불가 |
| 기타 | 7% | 4분 | - |

## 2. 시간대별 특징
- **10~12시**: 새벽배송 도착 이후 문의가 몰리는 시간. 이 시간대 문의의 **45%가 배송 조회**와 신선도 관련 교환·환불.
- **12~14시**: 점심시간을 이용한 직장인 고객 문의 증가. 주문 변경·취소 비중이 높음.
- **17~18시**: 다음 날 새벽배송 주문 관련 문의 (마감 시간, 주문 수정).

## 3. 개선 아이디어 (팀 회의에서 나온 의견, 미검토)
- 새벽배송 도착 직후 "배송 완료 + 사진" 알림 문자 발송 → 배송 조회 문의 감소 기대 (물류팀 협의 필요, 문자 비용 건당 약 9원)
- 앱 첫 화면에 '내 주문 배송 조회' 버튼 추가 (개발팀 공수 약 1주)
- 후처리 전담 시간을 10시대에서 15시대로 이동
- 점심 교대를 3개 조(11:30 / 12:30 / 13:30 출발)로 분산
- 콜백 예약 기능 도입 (대기 고객이 전화번호를 남기면 여유 시간대에 회신)
- 외부 아웃소싱 상담원 2명 추가 (월 약 700만 원)

## 4. 참고
- 상담 후 만족도 조사 응답률 12%, 만족도 평균 4.2/5.0

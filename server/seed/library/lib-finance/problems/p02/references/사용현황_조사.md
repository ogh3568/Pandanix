## 2. 클라우드 서버
- 개발·테스트 서버는 24시간 가동 중이나, 평일 20시~익일 08시와 주말의 CPU 사용률은 5% 미만.
- IT팀 추정: 개발 서버를 평일 업무 시간에만 자동 가동(스케줄링)하면 개발·테스트 서버 비용의 약 55% 절감 가능. 설정 작업은 IT팀 내부 3일 공수.

## 3. 복합기
- 월 출력량: 2023년 평균 32,000장 → 2025년 평균 14,000장 (전자결재 도입 영향).
- 5대 중 3층 2대는 하루 평균 출력 40장 미만. IT팀 의견: 3대로 충분.

## 5. 출장
- 1~9월 국내 출장 132건 중 당일 왕복 고객 미팅 61건.
- 영업팀 설문: 당일 미팅의 약 절반은 화상 미팅으로 대체 가능하다고 응답(48%).

## 6. 기타 (참고)
- 간식 선호도 설문: 커피 원두 만족도 4.1/5, 과자류 3.2/5. 직원 만족도 영향이 커 축소 시 반발 예상.
- 외부 교육은 2026년 역량 강화 계획에 따라 인사팀이 유지를 요청함.

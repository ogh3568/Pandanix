# 오픈 준비 리스크 워크숍 메모 (2025-12-12, 프로젝트룸)

참석: 본인(PM), 이준호, 박서연, 최민재, 정하은, 한지우, 윤채원(QA), 새길운송 PMO 강은솔 과장
진행: 포스트잇 브레인스토밍 후 받아 적은 그대로 정리(중복·정리 안 됨)

1. 트랙온 GPS 단말 펌웨어 업데이트가 1월 중순 예정이라고 함. 연동 규격이 바뀌는지 트랙온은 "아직 미정"이라고만 답변. (이준호)
2. 고객 배차팀에서 통합 테스트에 참여할 사람이 3명뿐. 연말 물량이 많아 하루 2시간 정도만 가능하다고 함. (강은솔)
3. 기존 시스템 기사 정보 1,240건 샘플 점검 결과 전화번호 중복·누락이 약 8%. 정제 담당이 아직 안 정해짐. (박서연)
4. iOS 앱 심사 반려되면 재심사 3~7일. 기사 중 iOS 사용자 약 35%. 심사 제출 예정일 1/7. (한지우)
5. 오픈일 1/19(월). 주말(1/17~18) 전환 작업 때 고객 IT 담당자는 1명만 대기 가능. (강은솔)
6. 운임 정산 2차 오픈(2/4) 개발과 통합 테스트 결함 수정이 둘 다 BE 인력(이준호·박서연)에 몰림. (이준호)
7. 기사 교육 대상 210명. 교육 가능한 시간은 대부분 야간·주말이고 50대 이상 기사가 46%. (정하은)
8. 부하 테스트 아직 안 함. 아침 피크 시간 동시 접속 약 300명 예상. (최민재)
9. 협력사(코드브릿지) 투입 인력 계약이 12/31 종료. 연장 여부 미정. (본인)
10. 오름정보기술 본사 2월 사무실 이전, 이삿짐 정리 일정 공지 예정. (정하은)
11. 지도 API 무료 한도 월 30만 건, 예상 사용량 월 45만 건. 초과분 과금 계약 미검토. (최민재)
12. 고객 PMO 강은솔 과장이 1월 인사이동 대상이라는 소문. 본인은 "모른다"고 함. (윤채원)
13. 팀 송년회 12/19와 고객 배차팀 송년회 날짜가 겹침. (한지우)

## 참고 수치
- 통합 테스트 시나리오 186건, 1일 처리 가능 목표 15건(고객 참여 기준).
- 지도 API 초과 과금 단가: 1,000건당 500원.
- 오픈 연기 시 고객이 기존 프로그램 유지보수 연장 비용 약 800만 원을 청구할 수 있음.

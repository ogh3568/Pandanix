# 리스크 평가 기준 (오름정보기술 PMO 표준)

## 1. 발생 확률(P)
| 점수 | 기준 |
|---|---|
| 1 | 10% 미만 — 거의 발생하지 않음 |
| 2 | 10~30% |
| 3 | 30~50% |
| 4 | 50~70% |
| 5 | 70% 이상 — 이미 징후가 나타남 |

## 2. 영향도(I) — 일정·비용·품질 중 가장 큰 영향 기준
| 점수 | 일정 | 비용 | 품질·업무 |
|---|---|---|---|
| 1 | 지연 없음 | 100만 원 미만 | 경미한 불편 |
| 2 | 1~2일 | 100~300만 원 | 비핵심 기능 일부 오류 |
| 3 | 3~5일 | 300~1,000만 원 | 비핵심 기능 장애, 우회 가능 |
| 4 | 6~10일 | 1,000~2,000만 원 | 핵심 기능(배차·위치 추적) 장애 |
| 5 | 오픈 연기 | 2,000만 원 초과 | 오픈 후 운영 중단 |

## 3. 등급
- 점수 = P × I
- **높음(15 이상)**: 대응 계획 즉시 수립, 주간 보고에 포함, 고객 PMO 공유
- **중간(8~14)**: 대응 계획 수립, 격주 점검
- **낮음(7 이하)**: 모니터링

## 4. 대응 전략 유형
- 회피: 원인을 없애거나 계획을 바꿔 리스크 자체를 제거
- 완화: 확률이나 영향을 낮추는 조치
- 전가: 계약·보험 등으로 책임을 제3자에게 이전
- 수용: 비용 대비 효과가 낮아 지켜보기만 함(비상 계획 준비)

## 5. 리스크 등록부 필수 항목
ID / 리스크 기술('~때문에 ~이 발생하여 ~에 영향' 형식) / P / I / 점수 / 등급 / 대응 전략 / 대응 조치 / 담당 / 트리거(징후)

※ 리스크는 '아직 일어나지 않은 불확실한 사건'이며, 이미 발생한 문제는 이슈 로그로 관리한다. 프로젝트와 무관한 사내 일정은 등록하지 않는다.

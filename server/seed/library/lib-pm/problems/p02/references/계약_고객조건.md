# 계약 및 고객 조건 요약 (새길운송 TMS)

## 1. 계약 조건
| 항목 | 내용 |
|---|---|
| 계약 금액 | 4억 8,000만 원 (VAT 별도) |
| 계약상 오픈일 | 2026-01-19 |
| 지체상금 | 수행사 귀책으로 오픈 지연 시 1일당 계약 금액의 0.05% (일 24만 원), 최대 10% |
| 대금 지급 | 착수 30% (지급 완료), 중도(설계 완료) 30% (지급 완료), 오픈 후 검수 완료 시 40% |
| 범위 변경 | 양측 합의서로 변경 가능. 단계 오픈(분할 오픈)도 합의 시 허용 |

## 2. 고객 측 일정 제약 (11/18 고객 PMO 회의)
- 2월 중순 설 연휴(2/16~2/18) 전후는 연중 최대 물동량 시기. 고객 PMO: "**1월 말까지 오픈 못 하면 3월 이후로 미뤄야 한다**."
- 기존 배차 프로그램 유지보수 계약이 1월 31일 종료되어, 3월 오픈 시 고객이 2개월 연장 비용(약 800만 원)을 부담해야 하며 이를 수행사에 청구할 수 있다고 언급.

## 3. 운임 정산 모듈 관련 고객 의견
- 고객 재무팀: 월 마감은 매월 5영업일. 1월분 운임 정산은 **2월 첫 주(2/2~2/6)**에 필요.
- 1월 1일~18일 정산은 기존 엑셀 방식으로 처리 가능. "정산 기능이 2월 4일까지만 가동되면 업무에 지장 없다."
- 정산 규칙 변경 요청(거리+중량 혼합제)은 11/18 승인 완료.

## 4. 참고
- 하자보수 기간: 오픈 후 1년, 월 1회 정기 점검.
- 고객사는 2026년 하반기 창고관리시스템(WMS) 발주를 검토 중이며, 이번 프로젝트 평가를 참고하겠다고 언급.

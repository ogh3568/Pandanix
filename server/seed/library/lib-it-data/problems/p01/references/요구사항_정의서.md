# 고객상담 헬프데스크 시스템 요구사항 정의서 (v1.2)

작성: 세온리테일 IT기획팀 / 검토: 고객경험(CX)팀 / 2026.9.30

## 1. 배경
현재 이메일(공용 메일함)·채팅(자체 개발 위젯)·카카오톡 채널(별도 관리자 페이지)로 상담이 흩어져 있어 이력 추적이 어렵고, 응답 지연에 대한 VOC 가 2026년 상반기 전년 대비 34% 증가했습니다. 상담 채널을 하나로 통합하는 SaaS 헬프데스크를 도입합니다.

## 2. 사용 규모
- 상담원 계정: **45명**(2026년 말 기준) → 2027년 하반기 **60명** 예상(신규 브랜드 런칭)
- 월 상담 건수: 약 38,000건 (이메일 41%, 채팅 33%, 카카오톡 26%)

## 3. 요구사항

| ID | 구분 | 요구사항 |
|---|---|---|
| R1 | 필수 | 이메일·웹채팅·카카오톡 채널 상담을 단일 화면에서 처리 |
| R2 | 필수 | 고객 개인정보는 **국내 리전**에 저장 (사내 개인정보 처리방침 제7조) |
| R3 | 필수 | 사내 IdP 연동 SSO(SAML 2.0) |
| R4 | 필수 | 주문관리시스템(OMS) REST API 연동 — 상담 화면에서 주문·배송 조회 |
| R5 | 필수 | **2027년 2월 15일 오픈** (설 연휴 이후 성수기 대비). 계약 체결 예정일은 2026년 11월 16일 |
| R6 | 선택 | 전화(CTI) 연동 |
| R7 | 선택 | AI 기반 상담 요약·답변 추천 |
| R8 | 선택 | 상담 품질 대시보드(응답시간·해결률) |

## 4. 예산
- **연간 라이선스(구독료): 7,000만 원 이내** — 2027년 하반기 60명 기준으로도 충족해야 함
- 일회성 구축비(연동 개발·이관·교육): 4,000만 원 이내
- 외화 결제 시 환율은 **1달러 = 1,380원**으로 가정

## 5. 평가 방법
- 필수 요구사항 미충족 벤더는 원칙적으로 탈락. 단, 오픈일 이전 충족이 계약서로 보장되면 조건부 검토 가능.
- 통과 벤더는 PoC 가중 점수(70%)와 3년 총소유비용(TCO) 점수(30%)로 비교.
- 3년 TCO = 구축비 + 3년 구독료(1년 차 45명, 2·3년 차 60명 기준) + 부가 비용.

## 6. 기타
- 기존 채팅 위젯 운영 서버는 2027년 3월 말 계약 만료.
- 상담 이력 이관 대상: 최근 2년치 약 87만 건.

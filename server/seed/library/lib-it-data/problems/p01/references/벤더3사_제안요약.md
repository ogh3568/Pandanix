# 벤더 3사 제안 요약 (제안서·견적서 기준, 2026.10.14 접수)

## 1) 헬프노트 (국내 SaaS, 설립 2014년, 고객사 약 1,200곳)
- 요금: 스탠다드 사용자당 월 89,000원 / **SSO 는 프로 요금제(사용자당 월 109,000원)에서만 제공**
- 채널: 이메일·웹채팅·카카오톡 기본 제공, CTI 는 제휴사 연동(별도 계약)
- 데이터 저장: 국내 리전(서울)
- API: REST, 분당 600회 호출 제한, 개발자 문서 공개
- 구축비: 1,500만 원 (OMS 연동은 고객사 개발, 헬프노트는 기술 지원)
- SLA: 가용성 99.9%, 장애 대응 1시간 이내
- 일정: 계약 후 8주 내 오픈 가능
- 기타: AI 요약 기능 2027년 상반기 출시 예정(추가 비용 미정)

## 2) 티켓온 (글로벌 SaaS, 국내 파트너사 통해 공급)
- 요금: 사용자당 월 **69달러**(SSO·AI 요약 포함), 연 단위 선결제
- 채널: 이메일·웹채팅 기본, **카카오톡은 서드파티 앱(월 30만 원)** 필요, CTI 기본 연동
- 데이터 저장: 현재 일본(도쿄) 리전, **국내 리전은 2027년 3월 오픈 예정**(파트너사 구두 안내, 계약서 명시 불가 입장)
- API: REST·Webhook, 분당 1,000회, 문서 풍부
- 구축비: 2,000만 원 (파트너사 수행, OMS 연동 포함)
- SLA: 가용성 99.95%
- 일정: 계약 후 10주

## 3) 케어링크 (국내 중소 SaaS, 설립 2019년, 직원 38명)
- 요금: **정액제** — 50석까지 월 450만 원 / 51~80석 월 560만 원 (SSO 포함)
- 채널: 이메일·웹채팅·카카오톡 기본, CTI 미지원(2027년 하반기 로드맵)
- 데이터 저장: 국내(자체 IDC + 국내 클라우드 이중화)
- API: REST, 호출 제한 없음(공정 사용), 문서 일부 미비
- 구축비: 3,000만 원 (OMS 연동 커스터마이징 포함)
- SLA: 가용성 99.5%
- 일정: 계약 후 12주
- 기타: 최근 2년 매출 성장률 연 40% 대, 2025년 영업손실. 동종 업계 레퍼런스 4곳.

## 공통
- 3사 모두 2년치 상담 이력 이관 지원(구축비에 포함).
- 계약 기간은 3사 모두 1년 단위 갱신, 2년 차부터 요금 인상률 상한 5% 제시(헬프노트·케어링크). 티켓온은 상한 없음.

# 한결시 보도자료 작성 지침 (홍보담당관실, 2026년 개정)

## 1. 기본 구성
1. **제목**: 25자 내외. 핵심 성과나 변화를 한 문장으로. 기관명은 앞에 붙이지 않는다.
2. **부제**: 1~2줄, 제목을 뒷받침하는 수치나 후속 계획.
3. **리드문**: 첫 문단 3문장 이내. 누가·언제·무엇을·왜를 담는다. "한결시(시장 ○○○)는" 형식은 쓰지 않고 "한결시는" 으로 시작한다.
4. **본문**: 중요한 내용 순(역피라미드). 문단당 3~4문장.
5. **인용문**: 시장(市長) 또는 담당 국장의 발언 1개. "~라고 밝혔다" 형식. 과장되거나 다른 지자체를 비교·비하하는 표현 금지.
6. **이용 안내**: 신청 방법, 연락처.
7. **문의처**: 담당부서·팀명만 표기(개인 실명·휴대전화 번호 표기 금지).

## 2. 표기 원칙
- 수치는 내부 자료와 정확히 일치해야 하며, 증가율은 소수점 첫째 자리까지 표기한다.
- 확정되지 않은 예산·계획은 "추진할 예정", "검토 중" 으로 표현한다.
- 이용자 후기는 공개 동의를 받은 경우에만 인용하며, 연령대·직업 정도로만 표기한다.
- 외래어·약어는 처음 나올 때 풀어 쓴다. 문장은 짧게, 능동형으로.
- '최초', '유일' 등 최상급 표현은 근거가 없으면 사용하지 않는다.

## 3. 분량과 형식
- 본문 A4 1장 이내(약 1,000~1,200자). 사진 설명은 별도 1줄.
- 배포일은 보도 희망일 하루 전, 엠바고 필요 시 제목 위에 표기.

## 4. 자주 지적되는 사례
- 리드문에 수치를 너무 많이 넣어 읽기 어려움 → 핵심 수치 1~2개만.
- 내부 행정 용어(예: '국비 매칭', '자체 사업') 그대로 사용 → 주민 눈높이로 바꿀 것.
- 성과만 나열하고 앞으로의 계획이 없음.

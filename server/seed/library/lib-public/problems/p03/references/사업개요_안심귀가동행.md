# 「한결 안심귀가 동행」 사업 개요

## 1. 사업 목적
늦은 시간 귀가하는 주민(여성·청소년·1인 가구 등)이 요청하면, 교육받은 2인 1조 동행 인력이 버스정류장·지하철역에서 집 앞까지 함께 걸어서 귀가를 돕는 서비스.

## 2. 운영 개요

| 항목 | 내용 |
|---|---|
| 시작일 | 2025년 10월 1일 |
| 운영 시간 | 매일 21시~다음 날 1시 (공휴일 포함) |
| 운영 지역 | 한결동·서림동·미호동·청솔동 전역 (4개 동) |
| 신청 방법 | 전화(안심귀가 상황실 031-000-1190) 또는 한결시 모바일 앱 '한결톡' → 안심귀가 메뉴, 도착 30분 전까지 신청 |
| 이용 대상 | 한결시 거주자 또는 시내 직장·학교 통학자 누구나 (사전 등록 필요) |
| 이용 요금 | 무료 |
| 동행 인력 | 경찰 출신 퇴직자·시니어 일자리 참여자, 범죄예방 교육 16시간 이수 |
| 담당부서 | 한결시 여성가족과 안전도시팀 |

## 3. 예산 및 목표
- 2025년 10월~2026년 9월 사업비: 2억 4,000만 원 (국비 30%, 시비 70%)
- 1년 목표: 동행 6,000건, 만족도 4.5점 이상
- 순찰 차량 2대 리스(월 98만 원/대), 동행 인력 유니폼·야광 조끼 지급

## 4. 2027년 계획 (내부 확정)
- 운영 지역을 신규 개발지구인 **솔빛동**까지 5개 동으로 확대 (2027년 3월 예정)
- 운영 시간 연장: 금·토요일은 새벽 2시까지
- 한결경찰서와 협약해 동행 중 이상 상황 발생 시 112 연계 체계 구축
- 2027년 예산(안) 3억 1,000만 원, 시의회 심의 중 (**확정 전이므로 보도자료에 확정 금액으로 표기하지 말 것**)

## 5. 이용자 후기 (만족도 설문 자유의견 중 발췌, 공개 동의 받음)
- "야근 후 골목길이 무서웠는데 이제 안심하고 퇴근해요." (30대 직장인)
- "딸이 학원 끝나고 올 때 이용하는데 부모로서 마음이 놓입니다." (40대 학부모)

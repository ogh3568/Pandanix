# 2027년 주민참여예산 후보사업 개요

사업부서가 제출한 사업계획서를 기획예산과에서 요약했습니다. 필요성·실행가능성 점수는 사업부서 및 외부 전문가 3인의 사전 검토 평균(5점 만점)입니다.

## 사업별 참고사항
- **A**: 5개소 중 2개소는 한결동 신규 단지 인근. 바닥분수는 7~8월만 운영.
- **B**: 22개소 중 9개소는 냉방기 사용 연한 15년 초과. 2025년 여름 경로당 온열질환 의심 신고 3건.
- **C**: 미호동 구간(1.6km)은 최근 2년간 야간 안전 민원 47건. 한전 협의 완료.
- **D**: 15개소 기준 5.1억이며, **12개소로 축소 시 4.1억**(유지비 3,400만)으로 조정 가능하다고 담당부서가 회신. 일부 정류장은 보도 폭이 좁아 설치 불가 여부 추가 확인 필요.
- **E**: 6개소 중 학교 3곳은 교육청 협의가 진행 중이며 확정되지 않음. 협의 무산 시 사업 규모가 절반으로 줄어듦.
- **F**: 임차 공간 사용. 운영비 9,000만 원은 주민참여예산이 아닌 일반회계에서 매년 별도 확보해야 함(일자리정책과 확보 여부 미정).

# 민원 처리기준 및 전년 동기 실적

## 1. 유형별 처리기한 (「한결시 민원처리 지침」 제12조, 근무일 기준)

| 민원유형 | 처리기한 | 담당부서 | 비고 |
|---|---|---|---|
| 불법주정차 | 3일 | 교통행정과 | 현장 단속 후 결과 회신 |
| 도로파손 | 5일 | 도로관리과 | 긴급(포트홀 30cm 이상)은 24시간 내 응급 보수 |
| 생활소음 | 7일 | 환경위생과 | 측정 장비 출동 필요 시 연장 1회 가능 |
| 쓰레기무단투기 | 7일 | 자원순환과 | 투기자 특정 시 과태료 부과 절차 별도 |
| 가로등고장 | 5일 | 도로관리과 | 한전 협조 필요 시 연장 가능 |
| 공원시설 | 7일 | 공원녹지과 | |
| 복지급여문의 | 3일 | 복지정책과 | 전화 상담 즉시 종결 건 포함 |
| 지방세·과태료 | 5일 | 세무과 | 이의신청은 별도 절차(30일) |

- **기한초과율** = 기한초과 건수 ÷ 접수 건수 × 100
- **재민원** = 같은 민원인이 같은 장소·내용으로 30일 이내에 다시 접수한 건

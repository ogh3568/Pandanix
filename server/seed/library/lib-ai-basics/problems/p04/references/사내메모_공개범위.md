# 사내 메모: 대외 공개 범위 (영업지원팀 내부용 — 거래처 공유 금지)

## 1. 지연의 실제 경위 (대외 비공개)
- 현미 원료 공급사의 수확 지연으로 원료가 6일 늦게 입고됨 → **대외 설명은 '원료 수급 지연' 까지만**.
- 원료 입고 후 생산 일정 재배정 과정에서 2공장 생산 계획 담당자의 입력 실수로 그래놀라 바 라인이 하루 비어 있었음 → **내부 문제, 거래처에 언급 금지**.
- 같은 주에 대형마트 B사 출시 물량(4만 개)을 우선 배정함 → **타 거래처 관련 내용 언급 금지**.

## 2. 보상 가능 범위 (영업팀장 승인)

| 항목 | 승인 범위 | 비고 |
|---|---|---|
| 2차 배송비 | 다온식품 전액 부담 | 이메일에 명시 가능 |
| 단가 할인 | **이번 이메일에서는 제안하지 않음** | 거래처가 요구할 경우에만 영업팀장 협의 후 최대 3% |
| 기획전 판촉 지원 | 시식 판촉 인력 2명 × 2일 지원 가능 | 거래처가 기획전 일정 차질을 언급하면 제안(이메일에 '추가 지원 방안 협의 가능' 정도로만 암시 가능) |

## 3. 표현 가이드
- '불가피하게', '부득이하게' 를 반복하지 말 것(책임 회피로 읽힘).
- 지연 사실에 대한 사과는 첫 문단에 한 번, 명확하게.
- 확정되지 않은 날짜를 약속하지 말 것: 11/25 납품은 생산팀 확정 완료. 11/20 이전 추가 생산은 불확실하므로 언급 금지.

## 4. 회신 이후 절차
- 최 과장 회신을 받으면 물류팀(내선 3307)에 배차 요청, 대체 품목 선택 시 품목코드 변경 발주서를 푸른마트에서 재발행받아야 함.
- 거래처가 전화로 항의할 경우 영업팀 강 과장에게 즉시 연결.

## 5. 기타 (참고)
- 푸른마트 연간 거래액은 약 9억 원으로 다온식품 유통 거래처 중 7위.
- 영업지원팀 연말 휴가 일정: 12월 넷째 주.

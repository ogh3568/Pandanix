# 모호한 요청 사례 모음

다온식품 사내 AI 활용 교육에서 수집한 실제 '아쉬웠던 요청' 사례입니다(내용은 교육용으로 각색).

## 사례 1. "회의록 정리해 줘"
- **결과**: 회의 내용을 시간 순서대로 길게 다시 써 줌. 결정사항과 할 일이 구분되지 않음.
- **문제**: 무엇을 위해(공유용? 보고용?), 어떤 형식으로(결정/할 일/일정) 정리할지 말하지 않음.
- **개선 예**: "아래 회의 메모를 팀 공유용으로 정리해 줘. ① 결정사항 ② 할 일(담당자·기한) ③ 다음 회의 안건 순서로, 각 항목은 한 줄씩, 전체 10줄 이내."

## 사례 2. "신제품 홍보 문구 좀 써 줘"
- **결과**: "건강한 하루의 시작!" 같은 평범한 문구 5개.
- **문제**: 제품 특징, 대상 고객, 사용할 채널(SNS? 매장 POP?), 글자 수 제한을 알려 주지 않음.

## 사례 3. "이거 요약해 줘" (30쪽 보고서 첨부)
- **결과**: 3문단 요약. 정작 필요했던 '예산 관련 내용' 이 빠짐.
- **문제**: 요약의 목적과 꼭 포함할 관점을 지정하지 않음.

## 사례 4. "엑셀 데이터 분석해 줘"
- **결과**: 평균·최댓값 등 기초 통계만 나열.
- **문제**: 알고 싶은 질문(어느 매장이 왜 떨어졌나?)이 없음. 계산 과정을 보여 달라는 요청도 없어 검증 불가.

## 사례 5. "좋게 고쳐 줘"
- **결과**: 문장이 화려해지고 길어짐. 원래 의도와 달리 과장된 표현이 추가됨.
- **문제**: '좋게' 의 기준(간결하게? 정중하게? 쉬운 말로?)이 없음.

## 좋은 프롬프트 체크리스트 (교육 자료)

| 요소 | 질문 | 예시 |
|---|---|---|
| 역할 | AI 가 누구처럼 답해야 하나? | "너는 10년 차 인사 담당자야" |
| 목적 | 결과물을 어디에 쓰나? | "신입사원에게 보낼 안내 메일" |
| 대상 | 누가 읽나? | "회사 사정을 모르는 신입" |
| 재료 | 꼭 들어갈 정보는? | 일정표, 준비물, 연락처 |
| 형식 | 어떤 모양으로? | 제목 + 표 + 체크리스트 |
| 제약 | 분량·톤·금지사항은? | "600자 이내, 존댓말, 이모지 금지" |

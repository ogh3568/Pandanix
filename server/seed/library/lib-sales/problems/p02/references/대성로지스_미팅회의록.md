# 대성로지스 이천 제2센터 요구사항 미팅 회의록

- 일시: 2025년 10월 14일(화) 14:00~15:10
- 장소: 대성로지스 이천 제2센터 현장사무소
- 참석: (대성로지스) 총무팀 정민호 과장, 안전보건팀 유가람 대리 / (맑은숨렌탈) 영업2팀 김태윤 팀장, 본인

## 1. 센터 개요
| 구역 | 면적 | 비고 |
|---|---|---|
| 작업장(입출고·분류) | 9,240㎡ | 지게차 상시 운행, 박스 분진 발생 |
| 사무동 | 660㎡ | 사무 인원 25명 |
| 휴게실·식당 | 330㎡ | 교대 시간 혼잡 |
| 랙 보관 구역 | 1,770㎡ | 무인 구역, 공기청정 불필요 |

- 근무 인원 220명, 2교대(주간 130명 / 야간 90명). 주간 130명 중 사무동 25명, 현장 105명.
- 오픈일: 2026년 1월 12일(월). 설치 가능 기간은 1월 5일~9일.

## 2. 고객 요구사항
1. **분진 대응**: 1센터 기준 작업장 미세먼지(PM10) 평균이 120㎍/㎥로 사내 기준(100) 초과. 안전보건 점검에서 지적받아 제2센터는 오픈 때부터 산업용 공기청정기 필수. (유가람 대리)
2. **냉수 부족 해소**: 1센터는 7~8월 정수기 냉수가 자주 떨어져 민원이 많았음. 휴게실·식당에는 대용량 정수기를 원함. 사무동에는 일반형 1대면 충분.
3. **작업 중단 없는 관리**: 필터 교체·점검은 작업 시간을 피해 야간(22시 이후) 또는 주말에 해 달라.
4. **예산**: 월 렌탈료 **500만 원 이내**(VAT 별도).
5. **계약·청구 통합**: 1센터와 계약 및 세금계산서 발행을 하나로 묶고 싶다.

## 3. 기타 논의
- 경쟁사 1곳(청정플러스)에도 견적을 요청함. 제안서는 **11월 7일(금)**까지 이메일 제출.
- 정민호 과장은 12월 셋째 주 휴가 예정, 그 기간 연락은 유가람 대리에게.
- 센터 내 주차 공간이 협소하므로 설치 차량은 사전 등록 필요.
- 센터 준공 행사(1월 12일) 때 협력사 화환은 받지 않는다고 함.

## 4. 후속 조치
- 맑은숨렌탈: 구역별 배치안과 월 렌탈료 견적을 포함한 제안서 작성
- 대성로지스: 구역별 도면(PDF) 10월 17일까지 송부

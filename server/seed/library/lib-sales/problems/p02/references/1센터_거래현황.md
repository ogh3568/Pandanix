# 대성로지스 1센터 거래 현황 (내부 자료)

## 계약 개요
| 항목 | 내용 |
|---|---|
| 거래 시작 | 2023년 7월 |
| 계약 기간 | 3년 약정, 2026년 6월 만료 |
| 렌탈 대수 | 90대 (IP-900 22대, AP-300 48대, WS-200 14대, WS-500 6대) |
| 월 렌탈료 | 약 544만 원 (3년 약정 10% 할인 적용, VAT 별도) |
| 2025년 1월 | 10대 증설 (80대 → 90대) |

## 서비스 실적 (2025년 1~9월)
- 방문 점검 이행률 100%, 고장 출동 평균 4.2시간.
- IP-900 설치 구역 PM10 측정값: 설치 전 평균 135㎍/㎥ → 설치 후 평균 72㎍/㎥ (2025년 3월 고객 공동 측정). 단, 1센터 작업장 일부는 IP-900이 부족해 평균 120㎍/㎥ 수준이 남아 있음.
- 냉수 고갈 민원: 7~8월 12건, 모두 WS-200 설치 구역(휴게실)에서 발생. 9월 이후 0건.
- 고객 만족도 조사(2025년 6월): 4.3/5. 개선 요청 1순위 "점검 방문이 작업 시간과 겹침".

| 분기 | 정기 점검 | 고장 출동 | 평균 출동 시간 | 주요 내용 |
|---|---|---|---|---|

## 담당 이력 (참고)
- 2023년 7월~2024년 6월: 영업1팀 담당, 2024년 7월부터 영업2팀 김태윤 팀장 담당.
- 고객 측 담당자는 2024년 12월에 정민호 과장으로 변경.

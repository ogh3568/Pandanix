# 맑은숨렌탈 B2B 제품 사양 및 가격표 (2025년 하반기)

## 1. 제품 사양 (월 렌탈료는 VAT 별도, 정가 기준)
| 모델 | 구분 | 적용 면적 / 권장 인원 | 주요 사양 | 월 렌탈료 |
|---|---|---|---|---|
| AP-300 | 사무용 공기청정기 | 99㎡ | H13 헤파필터, 소음 32dB | 3.9만 원 |
| IP-900 | 산업용 공기청정기 | 330㎡ | 세척형 프리필터 + H13, PM10 고농도 모드, 분진 센서 | 14만 원 |
| WS-200 | 스탠드형 냉온정수기 | 40명 이하 | 냉수 시간당 6L | 4.5만 원 |
| WS-500 | 대용량 냉온정수기 | 1대당 80명 | 냉수 시간당 18L, 냉수 탱크 2배 | 7.8만 원 |

## 2. 배치 기준
- 공기청정기: 구역 면적 ÷ 모델 적용 면적, 소수점 이하는 올림.
- 정수기: 동시 근무 최대 인원 ÷ 권장 인원, 소수점 이하는 올림.

## 3. 관리 서비스
- 기본: 월 1회 방문 점검·필터 교체(주간 방문). IP-900 프리필터 세척(월 2회) 포함.
- **야간·주말 방문 옵션**: 대당 월 5,000원 추가(할인 대상 아님).
- 고장 접수 후 24시간 이내 출동(수도권).

## 4. 할인 및 설치 조건
- 3년 약정: 렌탈료 10% 할인, 설치비 무료.
- 1년 약정: 할인 없음, 설치비 대당 3만 원.
- **통합 계약 할인**: 같은 고객의 통합 계약 총 대수가 100대 이상이면 신규 계약분에 추가 5% 할인(3년 약정 할인 후 금액에 적용). 기존 계약분은 재계약 시점부터 적용.

## 5. 참고 (B2B 제안과 무관)
- 가정용 모델 HP-100은 색상 3종(화이트·그레이·민트) 선택 가능.
- 2026년 1월부터 AP-300 후속 모델 AP-350 출시 예정(가격 미정).

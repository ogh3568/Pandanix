# 매체사·파트너 제안 요약 (10월 접수분)

마케팅팀 이수아 사원 정리 / 2026년 10월 22일

## 1. 별빛크리에이티브 (인플루언서 에이전시)
- 제안: 연말 선물 콘텐츠 패키지 **3,000만 원**
- 구성: 살림·인테리어 인플루언서 8명 (팔로워 10만 이상 2명, 2만~5만 6명), 콘텐츠 각 1건 + 스토리 2회
- 예상 성과: 매출 6,000만 원 내외 (에이전시 추정치, 보장 아님)
- 조건: 패키지 일부 축소 시 1인당 평균 375만 원으로 개별 계약 가능
- 비고: 3분기 협업 인플루언서 중 2명이 포함됨

## 2. 온에어미디어 (동영상광고 매체 대행)
- 제안: **2,500만 원 이상** 집행 시 노출량 15% 보너스 제공
- 연말 시즌 CPM(1,000회 노출당 비용)은 평소 대비 약 10% 상승 예상
- 신제품 런칭 영상 15초·30초 2종 운영 권장
- 비고: 보너스 노출은 구매 전환보다는 인지도 지표(조회수, 브랜드 검색량)에 영향

## 3. 모아몰 (제휴 쇼핑몰)
- 제안: 연말 선물 기획전 메인 구좌 입점, 노출 광고비 **1,500만 원** + 판매 수수료 12%
- 모아몰 연말 기획전 방문자 수: 전년 기준 약 180만 명
- 3분기 테스트(9월, 광고비 1,000만 원) 결과는 채널별 효율지표 자료 참고
- 비고: 모아몰 구매 고객 정보는 자사 회원으로 전환되지 않음 (재구매 마케팅 불가)

## 4. 기타 문의 (참고만)
- 지하철 역사 디지털 광고: 2주 2,000만 원. 측정 지표 없음. 이번 기획전에는 검토 제외 의견.
- 라디오 협찬: 단가 문의만 받음.

## 업체별 추가 정보
- **A안**: 강사진은 대기업 임원 출신. 교육장은 업체 연수원(경기 양평)으로 숙박 포함. 이동 시간 왕복 약 3시간.
- **B안**: 동종 업계 수료율 평균 78%. 실시간 워크숍은 매주 목요일 16:00~17:30 고정. 녹화본 제공.
- **C안**: 1:1 대신 **4인 그룹 코칭**(6회, 회당 1.5시간)으로 바꾸면 1인 120만 원. 그룹 코칭도 코치 1명당 최대 8명(2개 그룹).

# 신임 팀장 교육 요구사항 및 예산

작성: 인사팀 / 2026년 10월 10일

## 1. 대상
- 2025년 11월 ~ 2026년 10월 신규 선임 팀장 **24명** (개발 10, 영업 5, 고객성공 5, 경영지원 4)
- 평균 팀원 수 6.3명, 팀장 경력 평균 7개월

## 2. 예산
- 2026년 리더십 교육 잔여 예산: **4,000만 원**
- 고용보험 환급금은 다음 연도 교육 예산으로 귀속되므로, **예산 집행 기준은 환급 전 금액**으로 판단한다.
- 연내(12월 31일) 계약 체결 필수. 교육 종료는 2027년 2월까지 허용.

## 3. 신임 팀장 사전 설문 (24명 중 24명 응답)
| 가장 어려운 점 (복수 응답) | 비율 |
|---|---|
| 성과 면담·피드백 | 58% |
| 업무 위임 | 42% |
| 팀원 간 갈등 조정 | 33% |
| 상위 조직과의 소통 | 25% |
| 채용 면접 | 13% |

| 교육 형식 선호 | 비율 |
|---|---|
| 연속으로 3일 이상 자리를 비우기 어렵다 | 71% |
| 우리 팀 실제 사례로 배우고 싶다 | 63% |
| 온라인보다 대면이 좋다 | 38% |

## 4. 경영진 요구 (대표 메모)
- "교육 만족도가 아니라 **팀 운영이 실제로 달라졌는지** 확인할 수 있어야 한다."
- 12월 2~3주차는 연말 성과 평가 면담 기간이므로 이 기간에 교육 일정이 몰리지 않도록 할 것.
- 2026년 팀장 대상 몰입도 조사에서 신임 팀장 팀의 팀원 몰입도는 62점으로 기존 팀장 팀(71점)보다 낮았음.

## 5. 기타 참고
- 2025년 전사 교육 만족도 평균: 4.1 / 5.0
- 사내 대회의실(40석)은 화·목 오후 대관 가능

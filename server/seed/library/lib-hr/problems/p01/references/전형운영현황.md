## 3. 전형별 운영 메모
- **개발 과제**: 실무형 과제(API 서버 구현), 예상 소요 6~8시간. 제출 기한 7일. 채점은 현업 개발자 2인이 수행하며 채점 1건당 평균 1.5시간.
- **1차 면접**: 현업 면접관 2인, 60분 + 평가서 작성 30분. 개발 면접관 풀 9명 중 실제 참여는 5명에 집중.
- **2차 면접**: 개발직은 CTO가 단독 진행. CTO 면접 가능 슬롯은 주 2회(화·목 오후)로 고정되어 대기 발생.
- **처우 협의**: 연봉 테이블 밖 제안 시 대표 결재 필요(평균 3일 추가).

## 4. 기타 (참고)
- 사내 추천 채용: 상반기 9명 입사(전체의 18%), 추천 보상금 1인 200만 원 지급.
- 채용 박람회(5월) 참가비 400만 원, 현장 지원자 37명 중 입사 1명.
- 채용 홈페이지 리뉴얼은 9월 오픈 예정.
